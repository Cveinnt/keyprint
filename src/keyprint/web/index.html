03

What the lines can tell you.

The key influences choices during generation. Inspection replays the visible text and counts the resulting keyed bits. The chart shows the fraction of those bits equal to one, measured again at each text prefix.

The dotted 50% line is a visual reference, not a detection threshold. The other key is a control. Higher values are not confidence percentages. Editing can strengthen, weaken, or leave the diagnostic unchanged.

These are independent model samples. Their wording difference alone does not establish a quality effect. Prefixes can tokenize differently; no individual word is labeled “watermarked.” A weak or unavailable signal does not prove human authorship.

Use the same SDK in Python 
from pathlib import Path
from keyprint import Keyprint

wm = Keyprint.from_mlx("models/qwen3-8b-4bit",
    key=Path("keyprint.key").read_bytes())
result = wm.generate("Explain how a seed becomes a tree.")
inspection = wm.inspect(result.text)
print(result.text)
print(inspection.fraction)  # observed fraction, not confidence
