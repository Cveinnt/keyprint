    04

    What the lines can tell you.

    The key influences choices during generation. Inspection replays the visible text and counts the resulting keyed bits. The chart shows the fraction of those bits equal to one, measured again at each text prefix.

    The dotted 50% line is a visual reference, not a detection threshold. The other key is a control. Higher values are not confidence percentages. Editing can strengthen, weaken, or leave the diagnostic unchanged.

    The pair uses independent samples. Wording differences alone do not establish a quality effect. Prefixes can tokenize differently; no individual word is labeled “watermarked.” A weak or unavailable signal does not prove human authorship.

    Build your own experiment

    Install this recipe’s backend extra from the private checkout:

    python -m pip install '.[mlx]'

    Generate, compare, export. The same SDK produces this view and the live local playground. Recorded playback needs no model. New prompts and edits run in your local model.

    from keyprint import Keyprint

with Keyprint.from_mlx("path/to/qwen3-8b-4bit", key=Keyprint.new_key()) as wm:
    pair = wm.compare("Explain how a seed becomes a tree.")
    print(pair.marked)
    pair.export("my-demo")
