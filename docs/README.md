`src/keyprint/` is the SDK; `src/keyprint/web/` is its shared viewer. `tests/`
contains focused checks. `demos/` holds reviewed public recordings. `examples/`
contains starting points for new experiments. `evidence/` retains scoped results,
including failures. `sdk/` is the preserved historical reference, not the recommended
new installation. Its original licenses and attribution stay intact.
